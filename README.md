# hadoop-hive-taobao-analysis
# 基于Hadoop+Hive的淘宝用户行为大数据分析
重庆科技大学《Hadoop大数据技术实践》课程设计项目

## 项目简介
基于Docker搭建Hadoop+Hive分布式环境，对100万条淘宝用户行为数据进行清洗、分布式分析与可视化，核心分析用户行为分布、转化漏斗、24小时时段规律。

## 技术栈
- Hadoop（HDFS/YARN/MapReduce）
- Hive（HQL）
- Docker
- Python（数据预处理/可视化）
